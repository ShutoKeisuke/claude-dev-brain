# /cdb:idea

Web開発案出しのワークフローを開始します。

# 目的

ユーザーの方向性を整理し、Web開発案を生成・評価し、採用候補を作ること。

# ワークフロー

以下の順序で処理を行う：

1. direction-interviewer を使って方向性をヒアリング
2. ヒアリング結果を整理・要約
3. idea-generator を使ってWeb開発案を3つ生成
4. 各案を評価
5. 採用候補を提示

# 実行ルール

- 最初に必ず direction-interviewer を使用する
- ヒアリングが完了するまでアイデアは出さない
- ヒアリングは1問ずつ行う
- ユーザーの回答に応じて柔軟に進める
- 不要な質問は省略する
- ヒアリング結果が十分に揃ったら、簡潔に要約する
- 要約後、idea-generator を使用して3案を生成する
- まだファイル保存はしない

# ヒアリング完了の目安

以下がある程度わかれば、ヒアリングを終了してよい。

- 探索方向性
- 予算感
- 開発期間
- 個人開発かチーム開発か
- 出力先

# 最初のアクション

direction-interviewer を使用して、方向性ヒアリングを開始してください。

# ヒアリング完了後のアクション

ヒアリング結果を簡潔にまとめたうえで、idea-generator を使用してWeb開発案を3つ生成してください。
